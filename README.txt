HEBERGEMENT GRATUIT (GitHub Pages):
1. Créez un compte sur https://github.com (gratuit).
2. Créez un nouveau repository (projet) public. Exemple: bsi-engitech-site.
3. Décompressez le ZIP sur votre ordinateur.
4. Dans le repository, cliquez Add file > Upload files.
5. Glissez-déposez les fichiers du site (index.html, style.css, script.js et le dossier assets) à la racine du repository, pas le dossier bsi_site lui-même.
6. Cliquez Commit changes.
7. Ouvrez Settings > Pages.
8. Sous Build and deployment, choisissez Deploy from a branch; Branch: main; Folder: / (root), puis Save.
9. Après quelques minutes, GitHub affiche l'adresse publique de votre site.

GitHub Pages peut héberger gratuitement ce site. Pour connecter un domaine personnalisé, il faut posséder/renouveler le domaine et configurer les DNS. Les coûts du domaine sont indépendants de l'hébergement.

Si vous avez déjà un hébergement web Hostinger actif, vous pouvez aussi téléverser ces fichiers dans le dossier public_html de votre hébergement. Cela peut être inclus dans votre forfait Hostinger, mais ce n'est pas nécessaire pour GitHub Pages.
